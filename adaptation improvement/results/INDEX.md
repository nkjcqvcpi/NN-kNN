## Alternating retrieval and forests: ar4 (November 27, 2026)

Status: **complete, 1,848 new units**: 840 retrieval blocks, 840 refits and 168 selected tests. Four variants cover ExtraTrees/Random Forest × mixed/retrieved-only pairs, all 14 local datasets and seeds 40–42. Each starts from its recorded sequential forest and optimizer, runs five cycles of two retrieval epochs and a forest refit, then selects cycle 0–5 by validation. Gradients reach retrieval through aggregation; forest outputs and hard split decisions are detached.

Mixed-pair RF classification improves **3.636% → 3.191%** (two dataset wins, four ties, one loss). Retrieved-only RF regression improves **0.314232 → 0.313608**, only **0.20%** (five wins, one tie, one loss). The other three regression means slightly worsen. Validation keeps cycle zero in **52/168 models**; cycle-five validation error is worse than the start in **68/84 regression runs**. The merged result has 966 rows and 3,360 study units.

Retrieved-only RF regression wrong-direction / harmful-overshoot frequencies change **33.38% / 7.70% → 33.52% / 7.73%**; harmful squared-error increments fall **67.291 → 64.398**, but worsened-prediction frequency rises **43.37% → 43.62%**. Its selected retrieval-only RMSE worsens while the final prediction improves. Alternating does not resolve correction reliability. Keep sequential baselines; the RF continuations need fresh-split confirmation.

## Random Forest on matching pair formulations: ar3 (November 27, 2026)

Status: **complete, 252 new units**: 168 validation candidates and 84 selected-family test evaluations. Two RF families match the mixed and retrieved-only ExtraTrees pair recipes on all 14 datasets and seeds 40–42. Retrieval, features, targets, pair weights, aggregation and tree settings are fixed; ordinary RF changes threshold choice and enables bootstrap sampling. The merged output contains 1,512 study units and 798 comparison rows; all 672 previous rows are unchanged.

Retrieved-only RF reaches **3.325% / 0.314232 RMSE**, versus matching ExtraTrees' **4.350% / 0.314960**. Classification improves on Iris and Zebra Special, with five dataset ties. Regression improves only 0.23%, winning four of seven means and 12 of 21 seeds. Mixed RF reaches **3.636% / 0.321912**, improving classification but slightly worsening regression against mixed ExtraTrees. Expanded validation choice gives **3.586% / 0.317036**.

Retrieved-only RF fixes 60 classification retrieval errors and introduces six, versus ExtraTrees' 52/seven. Regression wrong-direction frequency falls 34.04% to 33.38%, but harmful overshoots rise 7.21% to 7.70%, and total harmful squared-error increases rise 50.741 to 67.291. Benefit rises too. Keep both forests for fresh-split confirmation; no default changed.

Six alternatives were tested against the old full adapter and its selected retrieval core: global on/off, global shrinkage, disagreement threshold, extra training without a gate, probability gate and utility-weighted gate.

The [full gate report](../code/neural-cbr/reports/ADAPTATION_GATE_LOCAL_2026-11-25.md) records the results and limits. A validation-selected disagreement threshold improves 5/7 classification and 5/7 regression task means; GMR changes are -3.68% and -0.52% versus the old full adapter. Both learned heads harm classification relative to their own full proposals. No default was changed; the original source runs are preserved.

## Local paired comparison: am1 (November 25, 2026)

Status: **complete, 42/42 pairs, no missing units**. The new design is better on 7 tasks and worse on 7. Geometric mean error is 3.68% higher for classification and 3.03% higher for regression. See the [full comparison report](../code/neural-cbr/reports/ADAPTATION_IMPROVEMENT_LOCAL_2026-11-25.md).

Behavior analysis: [under-correction, overshoot and direction report](../code/neural-cbr/reports/ADAPTATION_BEHAVIOR_2026-11-25.md), covering all 84 adapted units and 17,064 saved test evaluations. New classification adaptation fixes fewer errors (25 → 8) while causing fewer harmful flips (24 → 11). In regression, wrong-direction updates account for 90.12% of the new adapter's added squared error on harmed cases; Yacht also has increased destructive overshoot. Uniformly doubling corrections worsens both families' average errors. These are descriptive test-label diagnostics, not tuning recommendations.

## Learned disagreement cutoff: ag2 (November 25, 2026)

Status: **complete, 84/84 new units, 420 comparison rows, no missing units**. Two one-scalar gate variants are compared with all eight completed `ag1` methods. Mean classification error / standardized regression RMSE: frozen-adapter learned threshold **9.945% / 0.338856**; jointly trained threshold **9.359% / 0.347770**; validation-selected threshold **9.164% / 0.337424**. These previously inspected splits do not establish an improvement from making the cutoff trainable.
